<task type="auto">
  <name>Task 2: Implementera global sök i ReportService (raw + aggregated)</name>
  <files>src/services/ReportService.ts</files>
  <action>
- Utöka `RawAttendanceReportQuery` och `AggregatedAttendanceReportQuery` med `search?: string`.
- Implementera global sök som case-insensitive "contains" (regex) efter lookups, så sök kan matcha på berikade fält.

Minimikrav (QRY-04):
- Sök ska matcha minst `student.name` och `class.name`.

Rekommenderat (om enkelt):
- Inkludera även `class.instructor`.

Viktigt:
- Kombinera sök med andra postLookup-filter utan att skriva över varandras $or. Bygg ett `$and`-block om du behöver.
- Återanvänd `escapeRegExp()`.
  </action>
  <verify>pnpm test -- -t "ReportService"</verify>
  <done>
    - `search` påverkar resultat i både raw och aggregated
    - Sök kan kombineras med t.ex. status + klass-filter
  </done>
</task>

<task type="auto">
  <name>Task 3: Justera sorteringsregler enligt Phase 3 CONTEXT</name>
  <files>src/services/ReportService.ts, src/__tests__/services/ReportService.test.ts</files>
  <action>
Implementera följande (se D3-03..D3-06):

- Aggregated default-sort:
  - student/instructor/class: `presentCount desc` (tie-breaker stabilt)
  - session: `date desc` (senaste först), sedan start_time

- Textsort case-insensitive:
  - För sorts på strängfält, använd antingen collation på aggregation eller en normaliserad `toLower`-sortnyckel.

- Tomma värden sist:
  - För sorts på strängfält som kan vara ""/null (t.ex. notes, recorded_by), sortera först på en `__sortEmpty` (0/1) asc, sedan värdet.

- Raw: stöd `sortBy=notes`.

Lägg/uppdatera tester i `ReportService.test.ts` som verifierar:
- `search` filtrerar på student- eller klassnamn
- Aggregated default-sort för student ger högst `presentCount` först
- `sortBy=notes` fungerar och tomma hamnar sist vid asc (minst ett case)
  </action>
  <verify>pnpm test -- -t "ReportService"</verify>
  <done>
    - Tester täcker `search`, aggregated default-sort, och minst ett "tomma sist"-case
    - Inga regressions i befintliga report-tester
  </done>
</task>
